# CodePath Studio field manual

CodePath Studio presents programming as a set of hands-on experiments. Graphite and blue slate carry the reading surfaces. The console and lab grids sit one shade deeper. Soft periwinkle marks navigation and controls, while sage identifies live values, traveling signals, and earned mastery. Manrope handles headings and instructions. JetBrains Mono is reserved for code, addresses, values, and output.

The top bar provides access to the six sections. Profile information and the existing display and motion controls sit in the status bar. Overview opens with a live memory demonstration. Curriculum uses facing areas for the explanation and the worked example. The Notebook pairs a slate source editor with a darker output console. Progress combines a mastery summary with the track and achievement ledgers.

Lab diagrams are drawn in raylib. Contiguous slots encode array addresses, two distinct regions separate the stack and heap, offset frames represent calls, split nodes expose linked-list connections, and moving bars make comparisons and swaps legible. Commands and live state stay adjacent to the diagram. The startup animation uses the same address and value vocabulary, and the current skip and motion settings control its playback.

Motion follows the action. The intro signal establishes the order of the memory cells before the curtain reveals Overview. Navigation underlines travel between tabs, controls react within their existing hit areas, and question changes and answer feedback are visually distinct. Lab effects use the existing playback phase, so pause and seeking also control signal travel, allocation, returns, and swaps. Motion Off settles the presentation immediately.

Pointer links use a dedicated lane below memory cells. The wire and signal are painted after the geometry and join visible ports at the edges.
