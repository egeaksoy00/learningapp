# CodePath Studio field manual

CodePath Studio presents programming as a set of hands-on experiments. The interface uses white paper, lavender work surfaces, violet ink, and lime for the memory location or value currently in use. Manrope handles headings and instructions. JetBrains Mono is reserved for code, addresses, values, and output.

The top bar provides access to the six sections. Profile information and the existing display and motion controls sit in the status bar. Overview opens with a live memory demonstration. Curriculum uses facing areas for the explanation and the worked example. The Notebook pairs a light source editor with a dark output console. Progress combines a mastery summary with the track and achievement ledgers.

Lab diagrams are drawn in raylib. Contiguous slots encode array addresses, two distinct regions separate the stack and heap, offset frames represent calls, split nodes expose linked-list connections, and moving bars make comparisons and swaps legible. Commands and live state stay adjacent to the diagram. The startup animation uses the same address and value vocabulary, and the current skip and motion settings control its playback.
