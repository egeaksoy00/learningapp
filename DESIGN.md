# CodePath Studio visual system

## Direction

CodePath Studio is a code workbench. Lessons and the notebook use quiet,
legible surfaces. Live memory and algorithm models own the strongest depth,
light, and motion. The interface should read like a precise desktop tool that
invites exploration, with the active learning state unmistakable at a glance.

## Color

- Night ink `#101820` is the canvas.
- Slate `#182730` separates working regions.
- Mineral blue `#294452` marks structure and inactive controls.
- Chalk `#F4F0E8` carries primary reading text.
- Mist `#B8C4C5` carries secondary text.
- Signal orange `#FFB57A` marks the active step, live pointer, and primary action.
- Cyan `#83DBD6` marks code syntax and supporting connections.

Orange is reserved for the learner's current action or changing value. Cyan
shows a relationship or readable code, not an additional call to action.

## Type and layout

Manrope is the interface and heading face. JetBrains Mono is for code,
addresses, numerical state, and traces. Large headings identify the current
destination. Body copy uses comfortable line lengths and section spacing.
The navigation rail anchors the workspace. Home opens with a live memory
experiment and three course routes. Lessons place a scrollable syllabus above
a full-width reading desk. Labs use a vertical model selector, a broad 3D
simulation stage, a low code/state console, and a transport strip. Notebook
stacks a source editor above its compiler output. Progress gives mastery one
large instrument, then presents curriculum tracks and achievements.

## Components and motion

Flat working surfaces frame reading. Controls receive a full outline and
subtle fill on hover or selection. Simulation objects use distinct top,
front, and side planes with directional highlights and soft grounding shadows.
Pointer and data movement use eased travel along visible paths. Playback,
seeking, and the existing motion toggle control every educational transition.
Text and controls must remain legible at 1100×700 and in fullscreen.
